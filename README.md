# BookRadar 

Сучасна соціальна мережа та електронний каталог для книголюбів. Проєкт дозволяє знаходити літературу, трекати прочитані книги на персональних полицях та ділитися враженнями з ком'юніті.

Детальний опис архітектури, ролей та функціоналу MVP знаходиться у файлі [PRODUCT_SPEC.md](PRODUCT_SPEC.md).

## Технічний стек
- **Frontend:** React, TypeScript, Tailwind CSS, Vite
- **Backend:** Python, FastAPI
- **Database:** PostgreSQL
