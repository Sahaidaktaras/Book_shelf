# Product Specification: BookRadar

## 1. Суть проекту
BookRadar — це спеціалізована соціальна мережа та електронний каталог для книголюбів. Платформа поєднує в собі інструменти для трекінгу прочитаної літератури з можливостями соціальної взаємодії навколо книжкового контенту.

## 2. Проблема та рішення
**Проблема:** Існуючі платформи (наприклад, Goodreads) мають застарілий, перевантажений інтерфейс, працюють повільно і часто погано адаптовані під локальний (український) ринок книговидання. 
**Рішення:** Створення швидкого, сучасного Single Page Application (SPA), який дозволяє зручно шукати книги, організовувати персональну бібліотеку та ділитися враженнями у глобальній стрічці новин. Акцент робиться на швидкодію, зручний UX та якісну інтеграцію з українськомовним книжковим сегментом.

## 3. Ролі користувачів
* **Гість (Guest):** Може переглядати головний каталог книг, читати глобальну стрічку новин та переглядати детальні сторінки книг (відгуки, цитати).
* **Авторизований користувач (User):** Може додавати книги на власні "полиці" (читаю, прочитано, в планах), створювати дописи у стрічці, залишати лайки/коментарі, писати розгорнуті рецензії, додавати цитати та спілкуватися в чатах конкретних книг.
* **Адміністратор (Admin):** Має доступ до інструментів модерації (редагування метаданих книг, видалення невідповідного контенту чи користувачів).

## 4. Ключовий функціонал MVP
* **Каталог книг:** Пагінований список літератури з можливістю пошуку, сортування та фільтрації за жанрами.
* **Автоматизоване наповнення (Data Seeding):** Скрипти для імпорту великих масивів реальних книг через зовнішній Google Books API.
* **Персональні полиці:** Трекер статусу прочитаного для кожного користувача.
* **Глобальна стрічка (Social Feed):** Стрічка постів користувачів із можливістю прикріплення конкретної книги (через "розумний" пошук з debounce-контролем), системою лайків та вкладених коментарів.
* **Детальна сторінка книги:** Відображення рейтингу (вираховується автоматично на рівні БД), відгуків, цитат, посилань на книгарні та чату реального часу для обговорення твору.

## 5. Технічний стек
* **Frontend (Інтерфейс):** React, TypeScript, Vite. Для стилізації використовується Tailwind CSS. Архітектура: Mobile-First SPA.
* **Backend (Серверна логіка):** Python, фреймворк FastAPI для побудови RESTful API.
* **Database (База даних):** PostgreSQL з використанням драйвера `psycopg2`. Бізнес-логіка частково реалізована на рівні СУБД (тригери для перерахунку рейтингів, індекси для оптимізації повнотекстового пошуку).
